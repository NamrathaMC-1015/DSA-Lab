# DSA-Lab

A comprehensive collection of Data Structures and Algorithms implementations in C for learning and reference purposes.

## Overview

This repository contains implementations of fundamental and advanced data structures and algorithms. It serves as a practical resource for understanding how various DSA concepts work through well-documented C code.

## Contents

- **Data Structures**: Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, Hash Tables, etc.
- **Algorithms**: Sorting, Searching, Dynamic Programming, Graph Traversal, and more
- **Examples**: Practical applications and use cases for each data structure and algorithm

## Getting Started

### Prerequisites

- GCC (GNU Compiler Collection) or any C compiler
- Basic understanding of C programming
- Familiarity with command-line operations

### Compilation and Execution

To compile a C file:
```bash
gcc -o program_name filename.c
```

To run the compiled program:
```bash
./program_name
```

## Topics Covered

### Data Structures
- Linear Data Structures (Arrays, Linked Lists, Stacks, Queues)
- Non-linear Data Structures (Trees, Graphs)
- Hash-based Structures

### Algorithms
- Sorting Algorithms (Bubble Sort, Quick Sort, Merge Sort, etc.)
- Searching Algorithms (Linear Search, Binary Search)
- Dynamic Programming
- Graph Algorithms (DFS, BFS, Dijkstra, etc.)

## Usage

Each implementation is self-contained with clear comments explaining the logic. You can:

1. Review the code to understand the concept
2. Compile and run test cases
3. Modify and experiment with the implementations
4. Use as reference material for your own projects
